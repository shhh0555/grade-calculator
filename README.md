# 學期成績試算

輸入各科的評分比例和已公布成績，算出：

- 這學期的預估平均，以及停修某科後會變多少
- 還沒考的考試要考幾分，才能達到目標平均或單科門檻
- 某一科拿到幾分以下，停修才划算
- 還沒公布的項目裡，哪一項最值得花時間

## 怎麼用

雙擊 `index.html` 用瀏覽器打開，照步驟填：學期與目標 → 科目 → 評分項目 → 看結果。

資料只存在你的瀏覽器裡，不會上傳。換電腦前記得在結果頁按「匯出 JSON」備份。

## 測試

用瀏覽器打開 `tests/calc.test.html`，會顯示計算測試是否全部通過。

> 試算結果僅供參考，請以學校規定和授課老師說明為準。
